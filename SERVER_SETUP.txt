ПАМЯТКА: РАЗМЕЩЕНИЕ САЙТА «ИСКРА» И ОБЩЕГО СЧЕТЧИКА

Код сервера находится в server.js. Для общего счетчика нужен онлайн-хостинг, где можно запускать Node.js и хранить данные на постоянном диске. Один только статический хостинг (например, GitHub Pages) не подойдет.

ЧТО ПЕРЕДАТЬ СИСТЕМНОМУ АДМИНИСТРАТОРУ
- Все файлы проекта: iskra.html, script.js, styles.css, lit-photo.jpg, server.js и package.json.
- Требуется Node.js 18 или новее.
- Команда запуска: npm start.
- Сервер обслуживает сайт и API счетчика с одного домена.

НА ШКОЛЬНОМ СЕРВЕРЕ
1. Попросить администратора разместить все файлы проекта на сервере с Node.js.
2. Запускать приложение командой npm start, настроить его автоматический запуск после перезагрузки сервера и подключить HTTPS-домен.
3. Указать DATA_DIR как путь к постоянному каталогу для данных. В нем сервер создаст файл sparks.json.
4. Проверить сайт и адрес /api/sparks: последний должен вернуть JSON, например {"count":0}.
5. Открыть сайт на двух устройствах и проверить, что клик на одном сразу меняет цифру на другом.

ЕСЛИ РАЗМЕЩАТЬ НА RENDER
Render требует подключить GitHub-репозиторий. Для сохранения счетчика после перезапуска нужен постоянный диск; он доступен на платных сервисах. Перед созданием сервиса администратор должен проверить тарифы и согласовать оплату. В настройках сервиса указать команду запуска npm start и переменную DATA_DIR со значением пути монтирования диска, например /var/data.

ВАЖНО
- Не запускать несколько копий сервера: сейчас счетчик хранится в одном файле на диске.
- Регулярно делать резервную копию файла sparks.json.
- Для локальной проверки установить Node.js 18+, выполнить npm start в папке проекта и открыть http://localhost:3000. Локальный адрес доступен только на этом компьютере.
